# image_processing_by_OpenCL
 
image_processing_by_OpenCL - это библиотека C для быстрой, эффективной и удобной обработки изображений с использованием OpenCL. Она предоставляет широкий набор фильтров и алгоритмов, оптимизированных для параллельного выполнения на GPU. В качестве демонстрации возможностей библиотеки прилагается клиентское приложение на MFC с GDI+.

Основные особенности:
* Поддержка OpenCL для параллельной обработки;
* Медианный фильтр;
* Остальное пока в разработке.

Предварительные требования:
* Visual Studio 2019;
* OpenCL SDK (от Intel, NVIDIA или AMD);
* GDI+ (Graphics Device Interface Plus)

Установка OpenCL SDK:
1. Скачать и установить OpenCL SDK с веб-сайта производителя видеокарты (Intel, NVIDIA, AMD).
2. Убедиться, что переменные среды OpenCL настроены правильно.

Инструкции по сборке:
1. Клонировать репозиторий: `git clone https://github.com/lawrence-lis/image_processing_by_OpenCL.git`
2. Открыть решение `ImageProcessingLib.sln` в Visual Studio.
3. Выбрать конфигурацию сборки (Debug или Release).
4. Выбрать архитектуру сборки (x86 или x64).
5. Собрать решение.
